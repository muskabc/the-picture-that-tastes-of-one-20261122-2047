One close-up photograph of a single ripe strawberry, glistening with water drops against a dark background — the taste of one ingredient, strawberry, in a single picture.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, verifies the copy with a SHA-256 checksum, and sets the output file mode to 0644.
